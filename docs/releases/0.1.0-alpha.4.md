# ProduDash 0.1.0-alpha.4

This alpha ships **macOS Apple silicon (arm64) only**. No Windows or Intel macOS build is included.

## New interface

- Cohesive macOS-style navigation, contextual toolbars, compact operational lists, grouped settings and conversation panels across all seven sections.
- Light, Dark, Glass Light and Glass Dark appearances, plus system-following appearance. Existing ProduDash and Juanito branding remain.
- iMovie-inspired media browsing, preview transport and full-width interactive timeline; Numbers-inspired property groups, real revenue charts and read-only tables.
- Existing project editing, localization, approval, rendering, publishing and data-management controls remain available.

## Custom APIs and TikTok

- On-demand local API lifecycle controls: configure, start, stop, sign in and verify the expected account in Integrations → Custom APIs.
- TikTok browser conversation import, partial message snapshots, explicit manual messages and separate sending of approved AI drafts.
- Explicit TikTok publishing of approved completed renders, with account-bound approval snapshots, privacy options, operation history and honest processing/recovery states.
- The macOS installer now includes the API worker, runtime and production Playwright dependency. APIs stay off until started and stop when ProduDash quits.

**Google Chrome must be installed** for browser actions. TikTok uses a dedicated signed-in browser profile and is not an official TikTok API. Other unavailable connectors remain unavailable. Planned publishing times remain local reminders; no unattended sending or publishing is added.

## Data and verification

The application ID and per-user data location are unchanged. Existing projects, approvals, credentials and theme preferences are retained; no workspace reset is required. Local profiles, credentials and private acceptance evidence are excluded from the source commit and installer.

Validation covers 486 app unit tests, 31 standalone API tests, four Electron workflow tests, package-content and approved-media checks, and packaged startup/API lifecycle checks against the unpacked app, ZIP-extracted app and mounted DMG. The production dependency audit reports zero vulnerabilities. Packaging verification uses isolated data and does not send messages, upload media or make paid provider calls.

## Installation note

The DMG is **ad-hoc signed, not Developer ID signed or Apple notarized**. macOS may require explicit approval through Privacy & Security after copying ProduDash to Applications. This remains an alpha build. Checksums, the production dependency SBOM and build metadata accompany the DMG.
